Como funciona

Simples assim.

  1. Host cria a sala no app Android e compartilha um link ou QR code.

  2. Amigos entram pelo navegador — sem precisar instalar nada.

  3. Todos recebem a mesma pergunta e votam: Preto ou Branco.

  4. Quem votar com a maioria pontua. No fim, um pódio revela quem conhecia melhor o grupo.
